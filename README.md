## 🛠️ Tools & Library yang Digunakan

- **Bahasa Pemrograman:** Python
- **Notebook:** Jupyter Notebook / Google Colab
- **Library:**
  - `Pandas` — manipulasi dan analisis data
  - `NumPy` — komputasi numerik
  - `Matplotlib` & `Seaborn` — visualisasi data
  - `Scikit-learn` — machine learning (klasifikasi, clustering, regresi)
  - `SciPy` — komputasi ilmiah dan statistik
  - `TensorFlow/Keras` — deep learning (neural network)
  - `mlxtend` — association rules (Apriori)
  - `imbalanced-learn` — penanganan imbalanced dataset (SMOTE)

## 📝 Kesimpulan Umum Perjalanan Belajar (Pertemuan 1-13)

Sepanjang satu semester mempelajari Data Science, saya memahami perjalanan analisis data dari hulu ke hilir: dimulai dari pemahaman dasar data dan statistik deskriptif (Pertemuan 1-2), preprocessing dan visualisasi (Pertemuan 3-4), fondasi statistik inferensial berupa probabilitas, uji hipotesis, dan korelasi (Pertemuan 5-6), hingga memasuki dunia Machine Learning.

Pada fase regresi dan klasifikasi (Pertemuan 7-10), saya belajar membangun model prediktif mulai dari Linear Regression, Logistic Regression, Decision Tree, hingga Random Forest. Saya memahami pentingnya train-test split, metrik evaluasi yang tepat (precision, recall, F1, ROC-AUC), serta cara menangani dataset imbalanced pada kasus customer churn.

Fase unsupervised learning dan asosiasi data (Pertemuan 11-12) membuka wawasan tentang bagaimana algoritma dapat menemukan pola tersembunyi tanpa label, melalui K-Means clustering, hierarchical clustering, serta association rules (Apriori) untuk market basket analysis dan sistem rekomendasi.

Terakhir, Pertemuan 13 memberikan pengantar ke Deep Learning dan NLP, di mana saya membangun neural network pertama saya dengan TensorFlow/Keras dan melakukan analisis sentimen sederhana menggunakan TF-IDF.

Secara keseluruhan, mata kuliah ini membentuk fondasi yang kuat untuk eksplorasi lebih lanjut ke topik AI lanjutan seperti CNN, Transformer, dan LLM.
